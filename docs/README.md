# Documentación del proyecto

- `memoria.md` — fuente en Markdown de la memoria del PMV.
- `memoria.html` — versión con estilos de marca, lista para exportar a PDF.

## Generar el PDF

1. Abre `docs/memoria.html` en el navegador (doble clic).
2. **Imprimir** → **Guardar como PDF** (Ctrl/Cmd + P).
3. Ajustes recomendados: tamaño **A4**, márgenes **predeterminados**, activar
   **"Gráficos de fondo"** / **"Background graphics"** para conservar los colores.
4. Guarda como `docs/VibraMusic-PMV.pdf`.

> El HTML es autónomo (solo usa la fuente Afacad Flux de Google Fonts, con
> fallback Arial/Helvetica si no hay conexión).
